Garansi Update Materi: Setiap pembaruan arsitektur Google Apps Script, Scale Turbo, & CRM WhatsApp di tahun 2026 dapat diakses gratis tanpa biaya tambahan.

Membahas cara mencari niche yang punya daya beli tinggi tanpa harus perang harga:

  • Memilih format produk digital: E-Book vs Video Course vs Interactive Template.
  • Validasi ide 24 jam dengan survey organik media sosial.
  • Menghitung break-even point dan struktur penetapan harga psikologis.

Membangun etalase frontend terpisah di GitHub Pages dengan backend JSON murni bebas masalah CORS:

  • Teknik fetch POST menggunakan Content-Type text/plain;charset=utf-8 anti-preflight.
  • Panduan terminal Git & Personal Access Token (PAT) hingga live di GitHub Pages.
  • Optimasi CacheX ber-chunking (50 KB/partisi) & Warmup 3 lapis Scale Turbo.

Mencegah kehilangan calon pembeli dengan antrean non-blocking dan manajemen CRM terpadu:

  • Arsitektur AntrianNotif (0ms blocking di UI) + pemicu waktu 1 menit di luar LockService.
  • Normalisasi nomor 3 titik (08... di Sheet, 62... ke Fonnte) & validasi nomor aktif.
  • Blast WhatsApp ber-batch (10/20/50) dengan jeda acak & penghormatan status Opt-Out.

Standar keamanan kelas produksi dan upgrade versi aplikasi tanpa menyentuh database lama:

  • Zero literal secrets di Script Properties, verifikasi OAuth 2.0 tokeninfo, & sesi HMAC stateless.
  • Pola baca batch berbasis nama header, mode pindai Dry-Run, & Delta-Sync Upsert idempoten.

@github-pages-deploy-guide & @gas-pro-api

Asisten Deploy GitHub Pages & Struktur Folder

Ikuti perintah terminal di bawah secara berurutan. Jangan gunakan tombol "Upload files" di web GitHub agar struktur folder css/ dan js/ tidak hilang.

# 1. Inisialisasi & Push Pertama via Terminal
$ cd "C:\path\ke\folder\etalaseku-gas-pro"
$ git init
$ git add .
$ git commit -m "Initial commit EtalaseKu"
$ git branch -M main
$ git remote add origin https://github.com/USER/REPO.git
$ git push -u origin main
# Saat diminta Password, tempel Personal Access Token (ghp_...)

Checklist Wajib Sebelum Push:

  • ✅ Struktur Folder Utuh: Pastikan index.html berada di root, bersama subfolder css/style.css dan js/config.js + js/app.js.
  • ✅ Tanpa File Backend: Pastikan file Kode.gs tidak ikut di-push ke repositori publik GitHub.
  • ✅ Personal Access Token (PAT): Buat token klasik di github.com/settings/tokens dengan centang scope repo.
  • ✅ Perbaikan Cepat CSS/JS 404: Jika terlanjur rata di root, jalankan mkdir -p css js && git mv style.css css/style.css && git mv app.js js/app.js.
